# Code of conduct

Kyojin follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Be respectful and stay on topic: issues and pull requests are about the engine, the models and the numbers.
Report unacceptable behaviour to the maintainers through a private message on GitHub ([@YanissAmz](https://github.com/YanissAmz)).
Maintainers may edit or remove comments, issues and pull requests that break these rules.
